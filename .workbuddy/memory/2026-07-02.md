## Bug 修复：手机浏览器无法使用
**根因**：File System Access API (showOpenFilePicker) 在移动端浏览器不支持
**方案**：新增 localStorage 后备存储，自动降级
- 新建 `src/lib/localStorage.js` — localStorage 读写封装
- 修改 `src/store/useProjects.js` — 启动时检测 API 支持度，自动选择存储方式
  - 桌面端：优先 File System API
  - 移动端：自动降级到 localStorage
  - 新增 `ls-ready` / `ls-no-file` 状态
- 修改 `src/App.jsx` — 支持 `ls-ready` 状态渲染
- 修改 `src/components/FilePrompt.jsx` — 新增 `ls-no-file` 引导界面
- 修改 `index.html` — 添加移动端 meta 标签（viewport-fit=cover, apple-mobile-web-app）
- 添加 `gate-hint` CSS 样式
